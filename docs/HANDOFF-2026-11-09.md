## 4. Process lessons (Ariel's rules, learned the hard way)

- **Execute the written plan exactly.** If the plan does not decide something, or a step turns out hard, **stop and ask Ariel before writing code.** Writing a "deviation" or "correction" into the docs afterwards is not asking.
- **Never build a parallel or bespoke system when a reusable one exists.** W1 is the reusable window system. Extend it; do not replace it.
- **"Final Fantasy-like" means a skin in Ariel's own style,** not a pixel copy and not code written to imitate Final Fantasy.
- **"Start <packet>" means that packet's written scope, nothing more.**
- **In "questions only" turns, change no files.**
- **Ask the real choice in plain words.** Decision 0010 framed "replace W1" inside a decision note after Ariel asked for a review of Pixel Frame. That framing was not clearly put to her as "replace your system or reskin it".

## 5. Non-obvious facts (not visible from the repository alone)

**Repository and workflow**

- The repository is **public.** External art packs (LPC, Stone Soup and others) are never committed. `external/` and `public/external/` are ignored and guarded by `npm run check:external-art`. Fetch scripts are for other people.
- Do not commit `.claude/`. Stage explicit paths only, never `git add -A`. Push without force.
- Commit messages end with `[skip ci]` and the co-author line.
- **GitHub Actions:** the test matrix (`ci.yml`) is disabled (`gh workflow disable`). Ariel does not want Actions minutes used for tests: one evening of three-runner matrices used about 109 minutes. Don't re-enable it or dispatch workflows to "verify". `pages.yml` (build and deploy, no tests) runs only when Ariel asks for a publish.
- **Dependabot on Ariel's private `gsplat` repository** was the other big minutes user. A report was written for that repository's agent; it is outside this project.

**Tests**

- Playwright serves the built `dist/`. Run `npm run build:browser-fixtures` before browser tests, or they test a stale build.
- Full browser suite: about 7.5 minutes locally, 156 or more tests. Prefer running the specs for the area you changed, and say which ones you ran.
- **Movement timing:** `STEP_MS` is 160, and a held direction at the end of a step starts another step. Tests must release keys on the in-page reaction (`tapDirection` in `tests/browser/helpers.ts`), not after a fixed delay. A fixed 120 ms hold walked two tiles on the slow Windows runner.
- **Controller:** interact is button 2, cancel is button 1.
- **The Menu button opens the inventory first;** Settings is reached from there (`openTools` in the helpers).
- **The in-app browser tool's synthetic key presses do not reach the game.** To drive the game for screenshots, use a small Node Playwright script with real key presses against the dev server. The first load after code changes can take more than 10 seconds while Vite recompiles, so allow about 40 seconds.

**Build and tooling**

- `.ts` tools run with `node --experimental-strip-types` (Node 22.16 and 24.15 are both supported by `engines`). Type-only imports are erased; generated `.mjs` validators import fine.
- `tools/generate-schemas.mjs` rejects validators that need ajv runtime helpers. In schemas, don't use `minLength`/`maxLength` (use a pattern) or `null` inside an `enum`.
- **The production CSS minifier turns `border-image: none` into an empty, invalid declaration.** Use `border-image-source: none`. Dev builds don't minify, so the bug only appears in builds.
- On Windows, run anything with regex backslashes or nested quotes from a script file written with the Write tool. Heredocs into `node` lost backslashes more than once in this session.

**Rendering**

- **UNSCII 16 on canvas** is baked to a 1-bit bitmap font, because the TTF is anti-aliased by the browser at every size. Glyphs are rasterised at 8× and cell centres sampled.
  - `FontFace.family` returns a quoted name, so the code uses a constant family.
  - Phaser `RetroFont` size is the cell width (8), not 16.
  - Text is drawn with tint mode FILL and a (1, 1) shadow.
- **UNSCII in page text** keeps a one-pixel grey edge on Windows that CSS cannot remove.
- **Battle input** is an invisible DOM layer over the canvas: transparent, focusable buttons placed in logical pixels (`--x`/`--y`/`--w`/`--h`). Disabled entries stay focusable via `data-focusable-disabled`. The scene publishes `--game-left`, `--game-top`, `--game-width`, `--game-height`, `--game-scale` and `--ui-scale`.
- Phaser 4.2.1 has `NineSlice`.
- **The W1 manifest already declares `frame.band` and `frame.contentInsets`, but nothing reads them.** Window padding is hard-coded in CSS, and `TILE = 16` and the 192 × 192 atlas size are hard-coded in `layout.ts`, `paint.ts`, `windowskin.ts` and `audit-windowskin.mjs`. These are exactly the gaps plan 0011 closes.
- **The M5.3c "banded" blue fill is not a repeating band.** It's a single top-to-bottom gradient whose colours depend on the window's height. W1 tiles its fill tile (repeats, never stretches), so a repeating banded tile fits W1 with no code change; a whole-window gradient would be a small W1 addition (0011, D4).
- The UI gallery (`tests/ui-gallery`) is a separate Vite root with no `public/generated`, so anything served from `public/generated` is not available there.
