Controller configuration

Open MouseJoy-style controller test — same server, direct browser input, no Phaser or saved settings.

Xbox / Elite Series 2 defaults: left stick or D-pad to move; A for a pixel burst; X to interact/advance; B to close/cancel; Menu (button 9) opens the menu. In menus use up/down to select and left/right to adjust values. Existing remapped buttons are preserved. Press a controller button once, then release it, if detection is waiting. Gameplay pauses while this panel is open.

Names beside button/axis numbers describe the standard layout. For a non-standard layout, use the live numbers below. Unassign a button before moving it to another action. Bindings apply to the selected controller, not its firmware profiles.
